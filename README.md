# 数烈大戦 / SURETSU WARS (v1.3.8)

数字と「脚（コネクタ）」を持つタイルを盤面につなげて役を作り、目標スコア（Goal）の到達を競う対戦型パズル・ボードゲームです。

ブラウザ上で単体動作するHTML5のゲームとして公開しています。

_**一度は最後まで読んでね。**_

[▶ ゲームをプレイ](https://gggames-works.github.io/SURETSU-WARS/suretsu_wars_v1.3.8.html)

## 1. ゲーム概要・勝利条件

* **対戦形式**: あなた（Blue） vs CPU（Red）

* **勝利条件**:

  1. 画面上部の `Goal`（100 / 150 / 300 / 500 pt）に先に到達した側の勝利。

  2. 盤面の空きマスがすべて埋まった場合、その時点でスコアが高い側の勝利（同点の場合は引き分け）。

* **先攻・後攻**: ステージ確定（`CONFIRM`）時に 50% / 50% の確率でランダム決定されます。

## 2. 基本操作・ゲームの流れ

1. **ステージ準備・設定**

   * 画面上部のボタンでオプションを設定できます。

     * **CPUレベル**: `EASY` / `NORMAL` / `HARD` の切り替え

        (EASYがアイテムを使用しないのは、仕様です)

     * **Full Moon**: `OFF`（通常） / `ON`（盤面の特殊マスがすべてムーンマスになる特殊ルール）

     * **盤面サイズ**: `Portrait (7x7)` / `Landscape (9x7)` の切り替え

     * **BGM**: `BGM: OFF` / `BGM: ON`（Web Audio APIによるシンセBGM・SEの切り替え）

     * **Goal**: 目標スコア（100 / 150 / 300 / 500 pt）の選択

   * 別の盤面配置を引き直したい場合は `NEW STAGE` を押します。

2. **ゲーム開始**

   * 盤面を確認したら `CONFIRM` を押すと試合が開始し、先攻・後攻が抽選されます。

3. **自分のターンの操作**

   * **① 手札を選ぶ**: 画面下の `YOUR HAND`（4枚）から配置したいタイルを選択します。

   * **② 盤面に仮置きする**: 配置可能なマス（緑の破線枠）をクリックして仮置きします。

     * **1ターン目**: 壁以外の好きな空きマスに配置可能。

     * **2ターン目以降**: **自分のタイル（青）** または **レインボータイル（虹）** に上下左右で隣接する空きマスにのみ配置可能。

     * ※配置可能なマスが1つもない場合に限り、任意の空きマスへ配置できますが **ペナルティ（-50 pt）** が発生します。

   * **③ 回転・キャンセル**:

     * 仮置きしたタイルを再度クリックすると、時計回りに 90° ずつ回転できます。

     * やり直したい場合は `CANCEL` を押します。

   * **④ 確定**: `CONFIRM` を押すと配置が確定し、役判定・スコア計算が行われ、手札が1枚補充されます。

## 3. タイルの種類

| タイル | 特徴 | 
| ----- | ----- | 
| **自軍タイル（青 / 赤）** | 数字（1〜5）と1〜4方向の白い「脚」を持ちます。自分の色のタイルおよびレインボータイルと脚同士で接続できます。 | 
| **レインボータイル（虹）** | あなたとCPU共通の共用タイルです。青・赤どちらのタイルとも隣接配置・脚の接続が可能です。 | 
| **ワイルドタイル（☀ 太陽）** | レインボー属性に加え、スコア計算時に **1〜5のどの数字としても扱われる** 万能タイルです（最も高得点になる数字が自動適用されます）。 | 

## 4. 役とスコア計算ルール

自分のタイル（またはレインボータイル）同士で、**隣り合うタイルの「脚」が向かい合って接続されているネットワーク** において、今回配置したタイルを含む役が成立するとスコアを獲得します。

* **SEQ（連番 / ストレート）**: 接続された経路上で数字が1ずつ連続する（例: `1-2-3`、`4-3-2`）。

  * 得点: **タイル枚数 × 10 pt**（2枚以上で成立）

  * **5-STR ボーナス**: 5枚以上の連番が成立すると **さらに +50 pt**

* **SAME（同数）**: 接続されたグループ内で同じ数字が2枚以上つながる（例: `3-3-3`）。

  * 得点: **タイル枚数 × 10 pt**

* **LOOP（ループ / 環状）**: 接続された経路が3枚以上で輪（閉路）を作る。

  * 得点: **輪を構成する枚数 × 10 pt**

* **FULL（完全接続）**: 接続されたネットワーク全体のすべての「脚」が他のタイルとつながり、行き止まり（未接続の脚）が0個になる。

  * 得点: **ネットワーク全体の枚数 × 20 pt**

* **COMBO（複合役ボーナス）**: 1回の配置で上記4種類の役（SEQ / SAME / LOOP / FULL）のうち **2種類以上** を同時に成立させると発生。

  * 得点: **(成立した役の種類数 - 1) × 10 pt**

## 5. 特殊マス・ギミック

| マス表示 | 名称 | 効果 | 
| ----- | ----- | ----- | 
| **★（黄色）** | スターマス | このマスに配置して**何らかの役が成立したとき**、**+10 pt** のボーナスを得ます。 | 
| **ブラックホール（紫の渦）** | ホールマス | 成立した役のネットワーク内にこのマスが含まれていると、役ごとに **-10 pt** されます。 | 
| **☾（紫の三日月）** | ムーンマス | タイルを置くとルーレットが発動し、以下のいずれかに変化・発動します。 | 

・**STAR**: スターマスに変化（役成立で +10 pt）

・**HOLE**: ホールマスに変化（役に関与すると -10 pt）

・**SHUFFLE**: 盤面の壁・特殊マス・配置済みタイル・トラップの位置がランダムにシャッフルされます（このターンの役得点なし）

・**METEOR**: 配置マスを中心とした **周囲 3×3 マスのタイルとトラップをすべて消滅** させます（このターンの役得点なし） |

| **◆（水色ダイヤ）** | トラップ | アイテム `Set Trap` で設置された罠（相手からは見えません）。このマスを含む形で相手が役を成立させると **役得点が無効化され、-30 pt** となります。
ムーンマスにトラップを設置し、そのムーンマスがシャッフルの効果を発動した場合は、トラップは効果を発揮せず、他のタイルやマス同様シャッフルされます|

## 6. アイテム（1試合につき各1回まで使用可能）

自分のターン（タイル仮置き前）にポイントを消費して使用できます。

* **Rotate Piece（20 pt）**: 盤面にすでに置かれている任意のタイル1枚を選択し、90°単位で自由に回転させます（回転後、続けて手札の配置を行って `CONFIRM` で確定します）。

* **Shuffle Hand（10 pt）**: 自分の手札4枚をすべて新しいタイルに入れ替えます。

* **Set Trap（20 pt）**: 盤面の任意の空きマス（特殊マス上も可）にトラップを設置します。

* **Destroy（40 pt）**: 盤面にすでに置かれている任意のタイル1枚を破壊して消去します。

## 7. 動作環境・動作確認済み環境

HTML / CSS / JavaScript のみで構成されており、モダンブラウザで動作します。

* **スマートフォンでの推奨プレイ環境**: スマートフォンで遊ぶ場合は、**`Portrait (7x7)` の縦画面** でプレイしてください。横画面や `9x7` など、それ以外の画面向き・盤面サイズの組み合わせでは表示が崩れる場合があります。

以下の環境にて動作確認を行っています。

* **Windows**: Firefox,Vivaldi

* **Android**: Google Chrome,Fennec(Firefox派生)

* **iOS**    : Safari （開発者所有の環境ではないため、簡単な確認のみ）

※ iOS（Safari / Chrome）、Mac、Linux およびその他のブラウザでも閲覧・プレイ可能ですが、端末の画面サイズやブラウザの仕様によりレイアウトや音声再生の挙動が一部異なる場合があります。
